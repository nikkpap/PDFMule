## PDF Mule v1.7.0-rc1 — release candidate

### English
This is a **test version** (release candidate) of PDF Mule 1.7.0. It updates itself to the final 1.7.0 when that is out.
- **The programs it needs install themselves:** Tesseract OCR (with English, Greek and page orientation), Ghostscript and LibreOffice are installed automatically the first time a tool needs them. Windows asks you to answer Yes once; a Mac or Linux asks for your password.
- **Fixed:** PDF to Word stopped with "pixmap must be grayscale or rgb to write as png" on many printed books (CMYK pictures).
- **PDF to Word:** progress per page and an optional page range for big books.
- **HTML to PDF** prints web pages with Edge or Chrome, exactly as a browser shows them.
- **iPhone photos (HEIC)**, WebP and GIF in Images to PDF; more Office formats (ODT, RTF, ODP, ODS, CSV).
- **Clear error messages** instead of technical ones; details are kept in a log file.
- **Easier tool windows:** step 1 add files, step 2 options, step 3 run; short file names; drag to reorder.

### Ελληνικά
Αυτή είναι **δοκιμαστική έκδοση** (release candidate) του PDF Mule 1.7.0. Θα ενημερωθεί μόνη της στην τελική 1.7.0 όταν βγει.
- **Τα προγράμματα που χρειάζεται εγκαθίστανται μόνα τους:** Tesseract OCR (με Αγγλικά, Ελληνικά και προσανατολισμό σελίδας), Ghostscript και LibreOffice εγκαθίστανται αυτόματα την πρώτη φορά που τα χρειάζεται ένα εργαλείο. Τα Windows ζητούν ένα «Ναι»· σε Mac ή Linux γράφεις τον κωδικό σου.
- **Διόρθωση:** το PDF σε Word σταματούσε με «pixmap must be grayscale or rgb to write as png» σε πολλά τυπωμένα βιβλία (εικόνες CMYK).
- **PDF σε Word:** πρόοδος ανά σελίδα και προαιρετικό εύρος σελίδων για μεγάλα βιβλία.
- **HTML σε PDF:** οι ιστοσελίδες τυπώνονται με Edge ή Chrome, ακριβώς όπως φαίνονται στον browser.
- **Φωτογραφίες iPhone (HEIC)**, WebP και GIF στο Εικόνες σε PDF· περισσότερες μορφές Office (ODT, RTF, ODP, ODS, CSV).
- **Κατανοητά μηνύματα λάθους** αντί για τεχνικά· οι λεπτομέρειες κρατιούνται σε αρχείο log.
- **Πιο απλά παράθυρα εργαλείων:** βήμα 1 αρχεία, βήμα 2 επιλογές, βήμα 3 εκτέλεση· σύντομα ονόματα αρχείων· σύρσιμο για αλλαγή σειράς.
