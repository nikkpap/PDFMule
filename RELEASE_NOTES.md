## PDF Mule v1.6.0 — Windows, Mac and Linux apps that update themselves

### English
- **Ready-made apps:** PDF Mule now comes as a Windows **.exe**, a **Mac app** (Apple silicon and Intel) and a **Linux** program. No Python needed; OCR, Word, Excel, PowerPoint, Markdown and translation are built in.
- **Updates by themselves:** every version (.exe, Mac app, Linux, .pyw) checks GitHub a few seconds after it starts, shows what is new and, with your OK, downloads the update with a progress bar, checks it, and restarts into the new version.
- **Safe updates:** each download is checked against its SHA-256 checksum before anything is changed; on Windows and Linux the new version is saved next to the old one, which is removed after the update.
- **Mac:** Tesseract, Ghostscript and LibreOffice installed with Homebrew or in Applications are found automatically.
- Release notes in the update window are shown as clean text.

### Ελληνικά
- **Έτοιμες εφαρμογές:** το PDF Mule κυκλοφορεί πλέον ως **.exe** για Windows, **εφαρμογή Mac** (Apple silicon και Intel) και πρόγραμμα **Linux**. Δεν χρειάζεται Python· OCR, Word, Excel, PowerPoint, Markdown και μετάφραση είναι ενσωματωμένα.
- **Ενημερώνεται μόνο του:** κάθε έκδοση (.exe, Mac, Linux, .pyw) ελέγχει το GitHub λίγα δευτερόλεπτα μετά το άνοιγμα, δείχνει τι νέο υπάρχει και, με το ΟΚ σου, κατεβάζει την ενημέρωση με μπάρα προόδου, την ελέγχει και ανοίγει τη νέα έκδοση.
- **Ασφαλείς ενημερώσεις:** κάθε λήψη ελέγχεται με SHA-256 πριν αλλάξει οτιδήποτε· σε Windows και Linux η νέα έκδοση αποθηκεύεται δίπλα στην παλιά, που σβήνεται μετά την ενημέρωση.
- **Mac:** τα Tesseract, Ghostscript και LibreOffice (από Homebrew ή στο Applications) βρίσκονται αυτόματα.
- Οι σημειώσεις έκδοσης στο παράθυρο ενημέρωσης εμφανίζονται ως καθαρό κείμενο.
