PDF Mule - building the apps
============================

Releases are built automatically by GitHub Actions (.github/workflows/release.yml):
raise APP_VERSION in PDFMule.pyw, update RELEASE_NOTES.md, push to main.

To build by hand on Windows (same options as the workflow):

  py -m pip install --upgrade pyinstaller pillow certifi PyQt6 PyMuPDF pytesseract openpyxl python-pptx pdf2docx deep-translator pillow-heif "pymupdf4llm<1"
  py tools\build_info.py
  py -m PyInstaller --noconfirm --onefile --windowed --name PDFMule_v<version>-windows-x64 ^
     --icon pdf_mule_icon.ico --manifest PDFMule.manifest --version-file win_version.txt ^
     --add-data "pdf_mule_logo.png;." --add-data "pdf_mule_icon.png;." --add-data "pdf_mule_icon.ico;." ^
     --exclude-module tkinter --exclude-module weasyprint --exclude-module onnxruntime ^
     PDFMule.pyw

Mac (in Terminal): the same packages, then
  pyinstaller --noconfirm --windowed --onedir --name "PDF Mule" --osx-bundle-identifier gr.nikkpap.pdfmule \
     --icon pdf_mule_icon.png --add-data "pdf_mule_logo.png:." --add-data "pdf_mule_icon.png:." PDFMule.pyw

Notes:
- Tesseract, LibreOffice and Ghostscript are separate programs; PDF Mule finds them when installed.
- HTML to PDF (WeasyPrint) needs the GTK runtime and is only available in the .pyw.
- pymupdf4llm < 1 avoids the ~100 MB layout model that 2.x pulls in.
- Settings live in ~/.pdf_mule/ (Windows: %USERPROFILE%\.pdf_mule\).
