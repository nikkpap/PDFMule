PDF Mule v1.5.0 - example Windows PyInstaller build
=================================================

1. Install core + PyInstaller:
   py -m pip install --upgrade PyQt6 PyMuPDF Pillow pyinstaller

2. Optional integrations:
   py -m pip install --upgrade pytesseract pdf2docx python-pptx openpyxl weasyprint pymupdf4llm deep-translator

3. Build:
   py -m PyInstaller --noconfirm --clean --onefile --windowed ^
      --name PDFMule_v1.5.0 ^
      --manifest PDFMule_v1.5.0.manifest ^
      --icon pdf_mule_icon.ico ^
      --add-data "pdf_mule_logo.png;." ^
      --add-data "pdf_mule_icon.ico;." ^
      PDFMule.pyw

Notes:
- Tesseract, LibreOffice and Ghostscript are external programs and are not bundled automatically by the command above.
- For multiprocessing in a frozen executable PDF Mule calls multiprocessing.freeze_support().
- If an optional Python package uses extra data files, add the corresponding PyInstaller collect-data/collect-all option as required by that package/version.
- In a packaged EXE the Dependency status window detects add-ons but cannot pip-install them (pip would
  re-launch the EXE). Install every optional Python package you want BEFORE running PyInstaller.
- Settings and small UI assets live in %USERPROFILE%\.pdf_mule\
